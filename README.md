# TechBridge

Elder-friendly Android launcher app — big buttons, simple screens, fullscreen UI with no notification/navigation bars.

## APKs

All builds are inside the `all apks` folder:

| File | Version | What it includes |
|------|---------|------------------|
| `app-debug.apk` | Debug | First test build (debug) |
| `app-release.apk` | Test 1 | Release build, base launcher |
| `app-release-2.apk` | Test 2 | Permanent top/bottom bars, custom caller, Calendar, Calculator, Gallery, camera video |
| `app-release-3.apk` | Test 3 | Add & save contacts, custom keyboard, revamped calculator, gallery delete/sort, battery bar, Settings app |

## How to install

Download the APK to your phone, open it, and allow installation from unknown sources when prompted.
